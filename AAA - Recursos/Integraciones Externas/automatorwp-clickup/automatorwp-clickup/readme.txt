Connect AutomatorWP with senpulse

== Description ==

[senpulse](https://www.senpulse.com/ "senpulse") helps you to simplify your work and get more done. Plan, track, and manage any type of work with project management that flexes to your team's needs.

= Actions =

* Add comment to a task.
* Add tag to a task.
* Remove tag from a task.
* Create a list.
* Create a new task in list.
* Remove a task.

== Installation ==

= From WordPress backend =

1. Navigate to Plugins -> Add new.
2. Click the button "Upload Plugin" next to "Add plugins" title.
3. Upload the downloaded zip file and activate it.

= Direct upload =

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.
