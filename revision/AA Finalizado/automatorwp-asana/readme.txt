Connect AutomatorWP with Asana to automate your task management workflows.

== Description ==

[Asana](https://asana.com/ "Asana") is a leading project management tool that helps teams organize, track, and manage their work.

This integration allows you to automatically create tasks in Asana when triggers occur within your WordPress site.

= Actions =

* **Create task in Asana:** Automatically generates a new task in a specified Asana project. Supports custom task names, descriptions, and assignee IDs.

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Ensure AutomatorWP is active and you have an Asana Access Token.
