Connect AutomatorWP with TI WooCommerce Wishlist

== Requirements ==

* AutomatorWP
* WooCommerce
* TI WooCommerce Wishlist

== Description ==

[TI WooCommerce Wishlist](https://wordpress.org/plugins/ti-woocommerce-wishlist/ "TI WooCommerce Wishlist") is a plugin that allows your customers to create and manage wishlists of products in your WooCommerce store.

= Triggers =

* User adds a product to their wishlist.

= Tags =

* Product ID tag to use the product added to the wishlist on actions.

== Installation ==

= From WordPress backend =

1. Navigate to Plugins -> Add new.
2. Click the button "Upload Plugin" next to "Add plugins" title.
3. Upload the downloaded zip file and activate it.

= Direct upload =

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.
