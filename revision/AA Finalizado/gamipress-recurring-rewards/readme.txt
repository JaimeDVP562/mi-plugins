# Recurring Rewards for GamiPress

Recurring Rewards for GamiPress allows you to configure recurring point awards for users who unlock achievements or ranks.

## Features

- Create recurring rewards with periodic point distribution.
- Define unlock requirements using GamiPress achievements and ranks.
- Automatically award points on a recurring cycle.
- Support for multiple point types and repetition counts.

## Installation

1. Upload the plugin files to `/wp-content/plugins/gamipress-recurring-rewards`.
2. Activate the plugin from the WordPress Plugins screen.
3. Configure your recurring rewards from the GamiPress -> Recurring Rewards menu.

## Requirements

- WordPress 5.0 or newer.
- GamiPress installed and active.
- Compatible with GamiPress point types, achievements, and ranks.
