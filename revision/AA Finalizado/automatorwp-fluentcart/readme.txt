Connect AutomatorWP with FluentCart.

== Description ==

[FluentCart](https://fluentcart.com/ "FluentCart") is a modern eCommerce plugin for WordPress that lets you sell products, manage orders and handle subscriptions.

Connect AutomatorWP with FluentCart and automate your eCommerce workflows. React to new orders, subscription changes and more.

= Triggers =

* User completes a purchase.
* User activates a subscription.
* User cancels a subscription.

= Actions =

* Create a coupon.
* Add a note to an order.
* Cancel a subscription.

== Installation ==

= From WordPress backend =

1. Navigate to Plugins -> Add new.
2. Click the button "Upload Plugin" next to "Add plugins" title.
3. Upload the downloaded zip file and activate it.

= Direct upload =

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.

== Frequently Asked Questions ==

= Does this integration require any API key? =

No, this integration works directly with FluentCart installed on your WordPress site. No API key is required.

= Does this integration require FluentCart Pro? =

The integration works with the free version of FluentCart. Some triggers and actions related to subscriptions may require FluentCart Pro.
