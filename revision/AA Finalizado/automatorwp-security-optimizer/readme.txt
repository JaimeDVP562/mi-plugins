Connect AutomatorWP with Security Optimizer (SiteGround Security).

== Description ==

[Security Optimizer](https://wordpress.org/plugins/sg-security/ "Security Optimizer") is a security plugin developed by SiteGround that protects your WordPress site from attacks, blocks malicious users and monitors activity.

Connect AutomatorWP with Security Optimizer and automate your security workflows. Block users, block IPs and force password resets automatically when any automation is completed.

= Actions =

* Block a user.
* Unblock a user.
* Block an IP address.
* Unblock an IP address.
* Force all users to log out.
* Force all users to reset their passwords.

== Installation ==

= From WordPress backend =

1. Navigate to Plugins -> Add new.
2. Click the button "Upload Plugin" next to "Add plugins" title.
3. Upload the downloaded zip file and activate it.

= Direct upload =

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.

== Frequently Asked Questions ==

= Does this integration require any API key? =

No, this integration works directly with Security Optimizer installed on your WordPress site. No API key is required.

= Does this integration require SiteGround hosting? =

No, Security Optimizer works on any WordPress hosting. However, some features may require SiteGround hosting.
