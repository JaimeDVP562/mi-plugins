Connect AutomatorWP with WP WooCommerce Bookings

== Description ==

WP WooCommerce Bookings Allows customers to book appointments, make reservations or rent equipment without leaving your site.

= Triggers =

* User cancels a booking
* User pays a booking
* User unpays a booking

= Anonymous Triggers =

* Guest cancels a booking
* Guest pays a booking
* Guest unpays a booking

== Installation ==

= From WordPress backend =

1. Navigate to Plugins -> Add new.
2. Click the button "Upload Plugin" next to "Add plugins" title.
3. Upload the downloaded zip file and activate it.

= Direct upload =

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.
