Connect AutomatorWP with WP Super Cache.

== Description ==

[WP Super Cache](https://wordpress.org/plugins/wp-super-cache/ "WP Super Cache") is a static caching plugin for WordPress that generates HTML files served directly by Apache without processing comparatively heavier PHP scripts.

Connect AutomatorWP with WP Super Cache and automate your cache management. Purge caches automatically when any automation is completed.

= Actions =

* Purge all WP Super Cache caches.
* Purge WP Super Cache cache for a specific post.
* Purge WP Super Cache cache for a specific URL.

== Installation ==

= From WordPress backend =

1. Navigate to Plugins -> Add new.
2. Click the button "Upload Plugin" next to "Add plugins" title.
3. Upload the downloaded zip file and activate it.

= Direct upload =

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.

== Frequently Asked Questions ==

= Does this integration require any API key? =

No, this integration works directly with WP Super Cache installed on your WordPress site. No API key is required.
