Connect AutomatorWP with Short.io

== Description ==

[Short.io](https://wordpress.org/plugins/wp-shortcm/ "Short.io for WordPress") is the easiest way to generate short links for your WordPress posts.

= Actions =

* Create domain.
* Create short link.
* Redirect to a short link.
* Remove a link.
