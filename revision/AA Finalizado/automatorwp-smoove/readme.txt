Connect AutomatorWP with Smoove

== Description ==

[Smoove](https://www.smoove.io/ "Smoove") is a marketing automation and CRM platform that helps you manage customer relationships, email campaigns, and landing pages.

== Configuration ==

To use this integration working, you need to:

1. Log in to your Smoove account.
2. Generate an API Key with **[Full]** permissions.
3. Go to your WordPress admin area -> AutomatorWP -> Settings -> Smoove.
4. Paste your API Key and save changes.

= Actions =

* Create or update a contact.
* Get lists.
* Get landing pages.
* Get async contact status.

== Installation ==

= From WordPress backend =

1. Navigate to Plugins -> Add new.
2. Click the button "Upload Plugin" next to "Add plugins" title.
3. Upload the downloaded zip file and activate it.

= Direct upload =

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.
