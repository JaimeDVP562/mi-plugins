Connect AutomatorWP with W3 Total Cache.

== Description ==

[W3 Total Cache](https://wordpress.org/plugins/w3-total-cache/ "W3 Total Cache") is a popular WordPress performance plugin that improves server performance, caches every aspect of your site and integrates with CDNs.

Connect AutomatorWP with W3 Total Cache and automate your cache management. Purge caches automatically when any automation is completed.

= Actions =

* Purge all W3 Total Cache caches.
* Purge W3 Total Cache for a specific post.
* Purge W3 Total Cache for a specific URL.

== Installation ==

= From WordPress backend =

1. Navigate to Plugins -> Add new.
2. Click the button "Upload Plugin" next to "Add plugins" title.
3. Upload the downloaded zip file and activate it.

= Direct upload =

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.

== Frequently Asked Questions ==

= Does this integration require any API key? =

No, this integration works directly with W3 Total Cache installed on your WordPress site. No API key is required.
