Connect AutomatorWP with SG Optimizer.

== Description ==

[SG Optimizer](https://wordpress.org/plugins/sg-cachepress/ "SG Optimizer") is a performance optimization plugin developed by SiteGround that includes caching, file optimization and more.

Connect AutomatorWP with SG Optimizer and automate your cache management. Purge caches automatically when any automation is completed.

= Actions =

* Purge all SG Optimizer caches.
* Purge SG Optimizer cache for a specific URL.

== Installation ==

= From WordPress backend =

1. Navigate to Plugins -> Add new.
2. Click the button "Upload Plugin" next to "Add plugins" title.
3. Upload the downloaded zip file and activate it.

= Direct upload =

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.

== Frequently Asked Questions ==

= Does this integration require any API key? =

No, this integration works directly with SG Optimizer installed on your WordPress site. No API key is required.
