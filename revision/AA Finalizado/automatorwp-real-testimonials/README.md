# AutomatorWP – Real Testimonials

Integración personalizada para conectar **Real Testimonials** con **AutomatorWP** mediante un trigger.

## Qué hace
- Detecta la creación de testimonios (CPT: `spt_testimonial`)
- Dispara un evento en AutomatorWP para poder construir automatizaciones

## Hook utilizado
- `save_post_spt_testimonial`

## Cómo probarlo
Ver `TESTING.md`.

## Estado
Funcional y listo para revisión.
