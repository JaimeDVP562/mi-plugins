# AutomatorWP - Mistral AI Integration

Custom integration between **AutomatorWP** and **Mistral AI API**.

This plugin enables AI-powered actions within AutomatorWP by connecting to the Mistral API and processing prompts dynamically.

---

## 📌 Description

This project integrates Mistral AI with AutomatorWP to allow automated workflows powered by AI-generated responses.

The plugin provides:

- Admin configuration for API credentials
- Secure storage of API key
- API connection handler
- Prompt submission and response handling
- Basic error management

---

## 🚀 Features

- Admin settings page for API configuration
- Secure API key storage using WordPress options
- HTTP request handling to Mistral API
- JSON payload processing
- Response parsing and return to AutomatorWP workflows
- Basic validation and error handling

---

## 🛠 Technical Overview

- Built as a custom WordPress plugin
- Uses WordPress HTTP API (`wp_remote_post`)
- Hooks into AutomatorWP actions/triggers
- Modular structure with separation of logic
- Follows WordPress plugin development standards
