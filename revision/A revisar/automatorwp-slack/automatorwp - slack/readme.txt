Connect AutomatorWP with Slack

== Description ==

[Slack](https://www.slack.com/ "Slack") helps you to simplify your work and get more done. Plan, track, and manage any type of work with project management that flexes to your team's needs.

= Actions =
* Add channel.
* Add comment channel.
* Add comment thread.
* Add comment thread-list.
* Add comment user.
* Add reactin message.
* Add user to channel.
* Remove user from channel.

(Needs enterprise payment, not tested)
* Invite user to channel.
* Remove channel. 


== Installation ==

= From WordPress backend =

1. Navigate to Plugins -> Add new.
2. Click the button "Upload Plugin" next to "Add plugins" title.
3. Upload the downloaded zip file and activate it.

= Direct upload =

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.
