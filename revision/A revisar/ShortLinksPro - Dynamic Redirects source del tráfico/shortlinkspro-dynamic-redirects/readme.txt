Add dynamic redirects to your links!

== Description ==

Dynamic Redirects lets you add multiple target URLs to your links based on the conditions of your choice!

= Features =

* Rotation: Setup URLs with their our weight and to use one of them randomly.
* Geographic: Setup URLs based on the visitor's country.
* Technology: Setup URLs based on the visitor's technology (device, operating system and/or browser).
* Date Range: Setup URLs based on the date ranges in which the visitor visits the link.
* Time Range: Setup URLs based on the time ranges in which the visitor visits the link. These rule will apply every day!
* Clicks: Setup URLs based on the link's clicks.

== Installation ==

= From WordPress backend =

1. Navigate to Plugins -> Add new.
2. Click the button "Upload Plugin" next to "Add plugins" title.
3. Upload the downloaded zip file and activate it.

= Direct upload =

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.
