Connect AutomatorWP with BookingPress

== Description ==

[BookingPress](https://www.bookingpressplugin.com/ "BookingPress") is a WordPress appointment booking plugin that allows you to accept bookings online, manage appointments, and send automated notifications to your customers.

Connect AutomatorWP with BookingPress and automate your booking workflows. React to new bookings, status changes, and new customers automatically.

= Triggers =

* User completes a booking.
* Appointment status is changed.
* A new customer is created.

= Actions =

* Cancel an appointment.
* Approve an appointment.
* Reject an appointment.

== Installation ==

= From WordPress backend =

1. Navigate to Plugins -> Add new.
2. Click the button "Upload Plugin" next to "Add plugins" title.
3. Upload the downloaded zip file and activate it.

= Direct upload =

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.

== Frequently Asked Questions ==

= Where can I find the appointment ID? =

You can find the appointment ID in BookingPress -> Appointments. Each appointment has a unique ID shown in the list.

= Does this integration require BookingPress Pro? =

No, this integration works with the free version of BookingPress.
