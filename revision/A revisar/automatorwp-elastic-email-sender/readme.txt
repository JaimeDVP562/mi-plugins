Connect AutomatorWP with ElasticEmailSender.

== Description ==

Integration between AutomatorWP and ElasticEmailSender.

= Triggers =

* A elasticmailsender user completes a elasticmailsender event.

= Actions =

* Perform a elasticmailsender action.

== Installation ==

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.
