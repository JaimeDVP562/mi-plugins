Connect AutomatorWP with Funnels-mail-mint

== Description ==

[Funnels-mail-mint](https://getwpfunnels.com/email-marketing-automation-mail-mint/ "MailMint")is a WordPress plugin designed to streamline email marketing and lead management directly
within WordPress. It enables users to create targeted email sequences, segment contacts, and automate workflows, particularly for sales funnels and WooCommerce stores.

= Triggers =

* funnel completed
* funnel step submited

= Actions = 

* add suscriber

== Installation ==

= From WordPress backend =

1. Navigate to Plugins -> Add new.
2. Click the button "Upload Plugin" next to "Add plugins" title.
3. Upload the downloaded zip file and activate it.

= Direct upload =

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.
