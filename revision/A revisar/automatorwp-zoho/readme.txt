Connect AutomatorWP with Zoho CRM to automate your leads, contacts and tasks management.

== Description ==

**AutomatorWP - Zoho** allows you to connect your WordPress site with Zoho CRM. 

With this integration, you can automatically:
* Create new **Leads** in Zoho CRM when a user completes an action.
* Create or update **Contacts** based on WordPress activity.
* Assign **Tasks** to your sales team automatically.

== Installation ==

1. Upload the plugin folders to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to **AutomatorWP > Settings > Zoho CRM** to connect your account.

== Frequently Asked Questions ==

= Where do I find my Access Token? =
You can generate your API credentials in the Zoho Developer Console.
