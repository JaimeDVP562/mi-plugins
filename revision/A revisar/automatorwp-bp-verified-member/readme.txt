Connect AutomatorWP with Verified Member for BuddyPress.

== Description ==

Integration between AutomatorWP and Verified Member for BuddyPress. This add-on allows you to automate the process of giving or removing the verified blue badge from your community members, as well as reacting when a user gets verified or requests verification.

= Triggers =

* A user is verified.
* A user requests verification.

= Actions =

* Verify a user.
* Unverify a user.

== Installation ==

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.
